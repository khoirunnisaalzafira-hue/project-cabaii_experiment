# 🌶️ Website Warung Cabai Nusantara

Website 3 halaman bertema aneka cabai khas Indonesia yang dibuat menggunakan **HTML5, CSS3, dan JavaScript interaktif**. Dibuat dengan gaya bahasa santai, ramah, penuh humor kuliner, dan tidak kaku/korporat ("tidak terlalu profesional"), namun tetap memiliki tampilan visual yang memikat, modern, dan responsif.

---

## 📂 Struktur Halaman & Fitur Interaktif

### 1. [index.html](file:///c:/Users/User/Desktop/cabaii_experiment/index.html) - 🌶️ Cabai Rawit (*Capsicum frutescens*)
* **Julukan**: *Si Kecil Mematikan / Cabe Setan*
* **Fitur Interaktif 1 - Simulator Scoville**: Geser slider atau klik preset (15k - 110k+ SHU) untuk melihat perubahan ekspresi emoji (😊 -> 😅 -> 🥵 -> 🔥 -> 💀) dan tips pencegah lidah terbakar.
* **Fitur Interaktif 2 - Checklist Resep Sambal Korek Bawang**: Klik langkah-langkah ulek dan siram minyak panas dengan progress bar otomatis dan efek suara.
* **Fitur Interaktif 3 - Kartu Mitos vs Fakta**: Klik kartu untuk membalik dan mengetahui apakah biji cabai benar-benar yang bikin pedas atau bikin usus buntu.

### 2. [merah.html](file:///c:/Users/User/Desktop/cabaii_experiment/merah.html) - 🔴 Cabai Merah (*Capsicum annuum*)
* **Julukan**: *Si Cantik Merona Penjaga Warna Balado & Rendang*
* **Fitur Interaktif 1 - Kalkulator Porsi Bumbu**: Pilih menu (Sambal Balado, Bumbu Rendang, Ayam Rica-Rica) dan tentukan jumlah porsi orang (+ / -), sistem akan menghitung otomatis takaran gram cabai keriting, cabai merah besar, butir bawang, dan minyak goreng.
* **Fitur Edukasi - Komparasi Keriting vs Besar**: Perbedaan kadar air, rasa, dan fungsinya di dapur.
* **Fitur Interaktif 2 - Checklist Resep Sambal Balado Minang**: Panduan membuat sambal balado merah menyala dan tidak cepat menghitam.

### 3. [hijau.html](file:///c:/Users/User/Desktop/cabaii_experiment/hijau.html) - 🟢 Cabai Hijau (*Capsicum annuum var.*)
* **Julukan**: *Si Segar Gurih Primadona Nasi Padang*
* **Fitur Interaktif 1 - Kuis Penikmat Sambal Ijo**: 3 pertanyaan seru dengan feedback instan dan pemberian gelar sertifikat kehormatan kuliner.
* **Fitur Edukasi - 3 Kunci Emas**: Cara mengolah cabai hijau agar warnanya tetap hijau segar dan tidak pahit/langu.
* **Fitur Interaktif 2 - Checklist Resep Sambal Ijo Padang (Lado Mudo)**: Step-by-step masak sambal ijo khas rumah makan Minang.

## ✨ Fitur Global di Seluruh Halaman
* **Web Audio Synthesizer**: Efek suara desisan minyak panas (*sizzle*), pop tombol, dan fanfare kemenangan tanpa memerlukan file MP3 eksternal (menggunakan Web Audio API). Bisa di-mute/unmute lewat tombol 🔊 di navbar.
* **Mode Gelap / Terang (Spicy Dark Mode)**: Tomat/Chili red mode malam hari lewat tombol 🌙.
* **Animasi Partikel Cabai**: Klik di area tombol atau interaktif akan memunculkan partikel cabai dan api melayang.
* **Navigasi Lengkap**: Berpindah antar 3 halaman dengan mudah melalui header dan footer navigation card.
